# 릴리스 검증

현재 후보판은 형식 검사, 기본·개발 옵션의 clippy, 기본·개발 옵션의 단위 검사, vendor 해시 검사, Linux x86-64 musl 정적 빌드를 통과했습니다. 기본·개발·release 단위 검사는 각각 **103개 통과, 실패 0개**입니다.

배포 바이너리의 소스 해시를 현재 소스와 대조했고, 외부 공유 라이브러리와 `development-options`가 없음을 확인했습니다. 배포 파일의 SHA-256은 배포 `manifest.json`과 `SHA256SUMS.txt`에서 확인합니다.

두 도구의 최종 정적 바이너리로 CLI 22건을 검사했습니다. 도움말, 빌드 정보, 잘못된 속도·UID 거부, 이전 명령 호환, 합성 LiME의 전체 검증, 본문 변조 거부, 불완전 수집본의 종료 코드 2를 확인했습니다. 합성 파일은 검사 후 삭제했습니다.

## 실제 수집의 남은 확인

최종 수정본의 EC2 수집은 아직 완료하지 않았습니다. AWS 로그인 후 실제 Pod와 종료 대상 조건, 덤프 해시, 분석 도구 호환을 확인해야 합니다. 이전 후보판의 [WSL2 측정](history_codebase_candidate.md)은 최종 수정본의 EC2 검증을 대신하지 않습니다. 이 확인 전에는 main 병합과 공개 릴리스를 완료로 표시하지 않습니다.
